# ivgrf

A fork of `grf` for extended and modifed instrumental variable forests.

### Installation

The current development version can be installed from source using devtools.

```R
devtools::install_github("snorlax0302/ivgrf", subdir = "r-package/ivgrf")
```

Note that to install from source, a compiler that implements C++17 or later is required. If installing on Windows, the RTools toolchain is also required.
